# Folder Gambar

Taruh gambar Anda di folder ini dengan nama berikut agar otomatis tampil di website:

| Nama file            | Dipakai untuk                                  | Saran ukuran      |
|----------------------|------------------------------------------------|-------------------|
| `logo-tanjidor.png`  | Logo di navbar, hero, dan footer               | persegi, ≥ 400×400, latar transparan |
| `kampus.jpg`         | Latar belakang besar di bagian atas (hero)     | lanskap, ≥ 1920×1080 |
| `galeri-1.jpg` … `galeri-6.jpg` | Foto-foto di bagian Galeri Kampus   | ≥ 1200×800        |
| `ambassador-1.jpg` … `ambassador-8.jpg` | Foto profil para ambassador | persegi, ≥ 600×600 |

Kalau file belum ada, website tetap tampil rapi dengan placeholder.
